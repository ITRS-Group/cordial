# ITRS Level 2 Application Core Configuration

The `itrs.level2.application-core.xml` include file provides the common configuration and settings shared by all applications within your Geneos Gateway setup.

It is intended to be included at the Level 2 layer of your configuration hierarchy, ensuring that Level 3 - Application include files can build on these shared samplers and settings.

The include file contains three pre-defined samplers, selected as they are the most common for monitoring general applications.
