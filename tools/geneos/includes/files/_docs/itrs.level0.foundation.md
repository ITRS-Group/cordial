# ITRS Level 0 Base Configuration

The `itrs.level0.base.xml` include file provides baseline default configuration and settings for your Geneos Gateway and other ITRS Geneos Best Practice include files.

It is intended to be included at the base level of your configuration hierarchy, ensuring that all subsequent configuration layers inherit these fundamental settings.

Unlike other `itrs.*` include files, this does not have an associated `config.level0.base.xml` file and serves purely as a foundational include for setting up the base configuration. It establishes the core settings and defaults that all other configuration layers will build upon.
