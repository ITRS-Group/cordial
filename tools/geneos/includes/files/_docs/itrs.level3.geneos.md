# ITRS Level 3 Geneos Documentation

The `itrs.level3.geneos.xml` include files provide configuration and integration details for ITRS Level 3 Geneos monitoring, enabling seamless setup and management of monitoring agents, gateways, and dashboards within the Geneos ecosystem.

## Dependencies

This include file requires `itrs.level2.basic-application.xml` to be included beforehand, as it builds upon the configurations and integrations defined at Level 2 for Geneos monitoring.
