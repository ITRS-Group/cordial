# Incident Commands for the `geneos` Command

The `geneos incident` commands send event data to an Incident Management System (IMS) Gateway. The Gateway uses its configuration and the supplied fields to create or update incidents in the target platform.

Configure the target platform and field mappings in the standalone `ims.yaml` file. This file is separate from the main Geneos configuration and applies to incident operations invoked through the command.

Run `geneos help incident` for command options.
