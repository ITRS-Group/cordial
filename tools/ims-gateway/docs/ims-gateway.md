# `ims-gateway`

ITRS IMS Gateway


## Commands

| Command | Description |
|-------|-------|
| [`ims-gateway reload`](ims-gateway_reload.md)	 | Reload the configuration of the background ims-gateway |
| [`ims-gateway restart`](ims-gateway_restart.md)	 | Restart the background ims-gateway |
| [`ims-gateway sdp-auth`](ims-gateway_sdp-auth.md)	 | Authenticate against ServiceDesk Plus and store the token persistently |
| [`ims-gateway start`](ims-gateway_start.md)	 | Run an ims-gateway |
| [`ims-gateway status`](ims-gateway_status.md)	 | Show whether the background ims-gateway is running |
| [`ims-gateway stop`](ims-gateway_stop.md)	 | Stop the background ims-gateway |

### Options

```text
  -c, --conf string   override config file
```
