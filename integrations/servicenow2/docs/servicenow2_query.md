# `servicenow2 query`



## Usage

```text
servicenow2 query [FLAGS] [flags]
```

### Options

```text
  -t, --table string       servicenow table, defaults to incident
  -q, --query string       query
  -f, --format csv         output format: csv or json (default "csv")
  -r, --raw[=true|false]   turn ServiceNow sys_display off, i.e. return raw values instead of display values
  -c, --conf string        override config file
```
