# `servicenow2`

Geneos to ServiceNow integration


## Commands

| Command | Description |
|-------|-------|
| [`servicenow2 client`](servicenow2_client.md)	 | Create or update a ServiceNow incident |
| [`servicenow2 proxy`](servicenow2_proxy.md)	 | Run a ServiceNow integration proxy |
| [`servicenow2 query`](servicenow2_query.md)	 | Query ServiceNow incidents |

### Options

```text
  -c, --conf string   override config file
```
