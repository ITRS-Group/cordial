# Africa (AF) holiday calendars

> [!IMPORTANT]
>
> These calendars were built with AI/LLM assistance and have not been validated by humans. Verify dates and suitability before use, and review the [refresh runbook](RUNBOOK.md).

Snapshot gathered **2026-11-20**. See the [overall holiday calendar guide](README.md) for coverage limits, source-confidence grades and scheduling examples.

No verified African calendars are included in this snapshot, so there is no AF XML include yet. This does not mean that African jurisdictions have no holidays. Public, bank and exchange calendars need jurisdiction-specific sources; a regional grouping does not imply a shared calendar across countries.
